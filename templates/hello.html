Available API Endpoints

POST /api/scc/register_card
Register an RFID card for a user
POST /api/scc/verify_card
Verify if an RFID card is registered
POST /api/scc/verify_pin
Verify the PIN associated with a card
POST /api/scc/auth
Authenticate with card hash + PIN and get Samba access info
